Certificações

Geração e gestão de certificados de conclusão de curso.

Create certification

POST/api/v1/certifications/
Token de APIcertifications:createou sessão de usuário

Create a new certification template for a course. Certifications are awarded when a learner completes the course.

Corpo da requisiçãoapplication/jsonobrigatório

course_idintegerrequired
configConfig

Retorna

CertificationRead — Certification created.

idintegerrequired
certification_uuidstringrequired
course_idintegerrequired
configConfigrequired
creation_datestringrequired
update_datestringrequired
Respostas de erro
  • 403 Caller lacks permission to create certifications on this course
  • 404 Course not found
  • 422 Validation Error — HTTPValidationError
Requisição
Resposta
{
  "id": 1,
  "certification_uuid": "string",
  "course_id": 1,
  "config": {},
  "creation_date": "string",
  "update_date": "string"
}
