Zapier

O app oficial do Notoriun para Zapier permite construir fluxos no-code entre Slack, Google Sheets, HubSpot, Notion, Airtable, Mailchimp e qualquer outro app do Zapier — sem você precisar escrever um consumidor de webhook.

A integração com Zapier está disponível no plano Pro ou superior. Ela é implementada sobre o mesmo sistema de eventos dos Webhooks, então os dois podem ser usados juntos.

O Que Você Pode Fazer

Triggers (Notoriun → outros apps)

Todo evento do Catálogo de Eventos está disponível como trigger no Zapier. Quando esse evento dispara no Notoriun, o Zap roda e pode enviar dados para qualquer app suportado pelo Zapier.

Padrões comuns:

  • Curso Concluído → Slack: publica uma mensagem de celebração em um canal quando um aluno termina um curso.
  • Usuário Cadastrado → HubSpot: cria ou atualiza um contato quando alguém se cadastra na sua organização.
  • Tarefa Enviada → Google Sheets: adiciona uma linha para cada envio.
  • Certificado Reclamado → Mailchimp: marca o contato no seu público de newsletter.

Ações (outros apps → Notoriun)

Ações executam uma operação do Notoriun a partir de qualquer etapa de um Zap. Elas chamam endpoints administrativos existentes em /api/v1/admin/{org_slug}/* usando o token de API que você conectou.

AçãoO que faz
Matricular UsuárioMatricula um usuário existente em um curso.
Desmatricular UsuárioRemove a matrícula de um usuário em um curso.
Concluir AtividadeMarca uma atividade específica como concluída para um usuário.
Concluir CursoMarca um curso inteiro como concluído para um usuário.

Buscas

BuscaO que faz
Encontrar Usuário por E-mailBusca um usuário do Notoriun pelo e-mail — use o resultado para alimentar um ID de usuário em uma ação seguinte.

Configuração

1. Obtenha um token de API do Notoriun

  1. No dashboard do Notoriun, abra Configurações → Acesso à API.
  2. Clique em Criar token e dê a ele um nome descritivo (ex.: “Zapier”).
  3. Copie o token lh_… imediatamente. O token é restrito à sua organização atual.

Tokens de API são exibidos apenas uma vez, na criação. Guarde o valor em um lugar que você possa recuperar depois; se perdê-lo, revogue o token e crie um novo.

2. Conecte o app do Zapier

  1. No Zapier, clique em Create Zap e busque por Notoriun como o app de trigger.
  2. Escolha um evento (ex.: Curso Concluído) e clique em Continue.
  3. Quando solicitado a entrar, cole seu token de API lh_….
  4. O Zapier chama o endpoint /integrations/zapier/me do Notoriun para verificar o token e então exibe o nome da sua organização.

3. Configure o Trigger

Escolha o evento, opcionalmente filtre por curso ou grupo de usuários usando os menus dinâmicos que o Zapier preenche a partir da sua organização, e clique em Test trigger. O Zapier busca um payload de amostra recente para que você mapeie os campos na etapa de ação.

4. Ative o Zap

Quando você ativa o Zap, o Zapier chama POST /integrations/zapier/subscriptions no Notoriun com sua própria URL de callback. O Notoriun registra a assinatura (como um endpoint de webhook marcado com source="zapier") e começa a entregar o evento ao Zapier. Desativar o Zap remove a assinatura automaticamente.

Como Funciona Por Debaixo do Capô

A integração com Zapier é implementada sobre o pipeline de webhooks do Notoriun, usando o padrão REST Hooks do Zapier:

  1. O Zapier chama endpoints do Notoriun em /api/v1/integrations/zapier/* — /me para verificação de autenticação, /events para o catálogo de triggers, /courses / /users / /usergroups para as fontes dos menus dinâmicos, e /subscriptions para registrar callbacks.
  2. Cada Zap ativado registra uma assinatura, armazenada como um endpoint de webhook com source = "zapier", um único evento e a URL de callback do Zapier.
  3. Quando o evento dispara, o despachante de webhook existente entrega o payload ao Zapier usando as mesmas novas tentativas, guarda anti-SSRF e registro de entrega descritos em Webhooks.

Assinaturas aparecem no mesmo dashboard de Configurações → Automações que os webhooks manuais, identificadas com o nome do Zap que o Zapier informou no momento da assinatura. Você pode ver os logs de entrega de uma assinatura do Zapier da mesma forma que faria com um webhook manual.

As assinaturas continuam sendo calculadas e enviadas, mas o Zapier não as verifica — sua URL de REST Hook é protegida pelo próprio caminho secreto dele. Você não precisa fazer nada com a assinatura como usuário final.

Gerenciando Assinaturas do Zapier

  • O lugar canônico para ativar/desativar um Zap é a interface do Zapier. Ativar ou desativar um Zap lá adiciona ou remove a assinatura correspondente no Notoriun.
  • Excluir uma assinatura pelo dashboard do Notoriun vai parar as entregas, mas o Zapier não vai saber que a assinatura desapareceu — o Zap simplesmente vai deixar de receber qualquer coisa, silenciosamente. Prefira desativar o Zap a partir do Zapier.
  • Se você revogar o token de API subjacente, todo Zap conectado com aquele token vai falhar ao tentar se reinscrever na próxima sincronização do Zapier. Crie um novo token e reconecte a conta no Zapier.

Endpoints de Integração com o Zapier

Esses endpoints são chamados pela Plataforma Zapier em nome da sua organização — normalmente você não vai chamá-los diretamente, mas eles estão documentados aqui por completude.

MétodoEndpointPropósito
GET/api/v1/integrations/zapier/meTeste de autenticação; retorna a identidade da organização e do token
GET/api/v1/integrations/zapier/eventsRegistro completo de eventos com esquemas
GET/api/v1/integrations/zapier/coursesLista de cursos para os menus dinâmicos (máx. 500)
GET/api/v1/integrations/zapier/usersLista de usuários para os menus dinâmicos (máx. 500)
GET/api/v1/integrations/zapier/usergroupsLista de grupos de usuários para os menus dinâmicos (máx. 500)
POST/api/v1/integrations/zapier/subscriptionsChamado quando um Zap é ativado
GET/api/v1/integrations/zapier/subscriptionsLista as assinaturas de Zap da sua organização
DELETE/api/v1/integrations/zapier/subscriptions/{id}Chamado quando um Zap é desativado ou excluído

Todos os endpoints do Zapier exigem Authorization: Bearer lh_… — o escopo da organização é transportado pelo token, então nenhum org_id aparece na URL.

Solução de Problemas

  • “This endpoint requires an API token” — Você tentou conectar com autenticação por cookie de sessão em vez de um token lh_…. Gere um em Configurações → Acesso à API.
  • “Zapier integration requires a Pro plan or higher” — Faça upgrade do plano da organização; os endpoints do Zapier são restritos ao plano Pro.
  • “Unknown event” — O app do Zapier foi publicado com um nome de evento que não existe mais no Notoriun (ou vice-versa). Confirme que o app do Zapier e a instância do Notoriun estão em versões compatíveis.
  • O Zap roda, mas nenhum dado chega — Confira Configurações → Automações no Notoriun; a linha da assinatura mostra as tentativas de entrega recentes, seus status e o corpo de resposta que o Zapier retornou.
  • Bloqueio de SSRF — A URL de callback do Zapier é pública, então isso não deveria acontecer em produção. Se acontecer, confira o error_message do log de entrega — ele vai explicar qual IP foi bloqueado.
