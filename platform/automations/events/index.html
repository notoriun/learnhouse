Catálogo de Eventos

Todo evento que pode disparar a partir do Notoriun, agrupado por categoria. Cada evento entrega o mesmo envelope (event, delivery_id, timestamp, org_id, data) — só o formato de data varia.

O registro de eventos é a fonte única da verdade. Em produção, os payloads despachados são validados contra esses esquemas, e qualquer divergência é registrada como aviso. Você também pode buscar o registro em tempo real na sua instância do Notoriun:

GET /api/v1/{org_id}/webhooks/events

Sistema

ping

Evento de teste enviado para verificar a conectividade do endpoint. Disparado pelo botão Enviar evento de teste e pelo endpoint POST /webhooks/{uuid}/test.

{ "message": "string" }

Progresso de Aprendizagem

course_completed

Disparado quando um usuário conclui todas as atividades de um curso.

{
  "user":   { "user_uuid": "string", "email": "string", "username": "string" },
  "course": { "course_uuid": "string", "name": "string" }
}

course_enrolled

Disparado quando um usuário se matricula em um curso.

{
  "user":   { "user_uuid": "string", "email": "string", "username": "string" },
  "course": { "course_uuid": "string", "name": "string" }
}

activity_completed

Disparado quando um usuário conclui uma atividade.

{
  "user":     { "user_uuid": "string", "email": "string", "username": "string" },
  "activity": { "activity_uuid": "string", "activity_type": "string" },
  "course":   { "course_uuid": "string", "name": "string" }
}

assignment_submitted

Disparado quando um usuário envia uma tarefa.

{
  "user":       { "user_uuid": "string", "email": "string", "username": "string" },
  "assignment": { "assignment_uuid": "string" },
  "course":     { "course_uuid": "string", "name": "string" }
}

assignment_graded

Disparado quando um instrutor corrige o envio de uma tarefa.

{
  "user_id": "integer",
  "assignment_uuid": "string",
  "course_uuid": "string",
  "grade": "integer"
}

certificate_claimed

Disparado quando um usuário recebe um certificado.

{
  "user":        { "user_uuid": "string", "email": "string", "username": "string" },
  "course":      { "course_uuid": "string", "name": "string" },
  "certificate": { "user_certification_uuid": "string" }
}

Usuário e Acesso

user_signed_up

Disparado quando um novo usuário se cadastra na organização.

{
  "user": {
    "user_uuid": "string",
    "email": "string",
    "username": "string",
    "first_name": "string",
    "last_name": "string"
  },
  "signup_method": "string"
}

user_email_verified

Disparado quando um usuário verifica seu endereço de e-mail.

{ "user_uuid": "string", "email": "string" }

user_role_changed

Disparado quando o papel de um usuário é alterado na organização.

{ "user_id": "integer", "org_id": "integer", "new_role_uuid": "string" }

user_invited_to_org

Disparado quando usuários são convidados para a organização. Um único evento é disparado por lote de convite.

{
  "org_id": "integer",
  "emails": "list[string]",
  "invite_code_uuid": "string",
  "invited_by": "string"
}

user_removed_from_org

Disparado quando um usuário é removido da organização.

{ "user_id": "integer", "org_id": "integer" }

Ciclo de Vida do Curso

course_created

Disparado quando um novo curso é criado.

{ "course_uuid": "string", "name": "string", "org_id": "integer" }

course_published

Disparado quando um curso é publicado ou despublicado.

{ "course_uuid": "string", "name": "string", "published": "boolean" }

course_deleted

Disparado quando um curso é excluído.

{ "course_uuid": "string", "name": "string" }

course_update_published

Disparado quando um comunicado é publicado em um curso.

{ "courseupdate_uuid": "string", "course_uuid": "string" }

Gestão de Conteúdo

activity_version_created

Disparado quando um snapshot de versão de atividade é criado.

{ "activity_id": "integer", "version_number": "integer", "created_by_id": "integer" }

activity_version_restored

Disparado quando uma atividade é restaurada para uma versão anterior.

{
  "activity_uuid": "string",
  "restored_version_number": "integer",
  "new_version_number": "integer"
}

course_contributor_added

Disparado quando colaboradores são adicionados a um curso.

{ "course_uuid": "string", "contributors": "list[object]" }

course_contributor_removed

Disparado quando colaboradores são removidos de um curso.

{ "course_uuid": "string", "contributors": "list[object]" }

collection_created

Disparado quando uma nova coleção de cursos é criada.

{ "collection_uuid": "string", "name": "string" }

podcast_episode_created

Disparado quando um novo episódio de podcast é adicionado.

{
  "episode_uuid": "string",
  "podcast_uuid": "string",
  "title": "string",
  "episode_number": "integer"
}

Colaboração

board_created

Disparado quando um novo quadro branco é criado.

{ "board_uuid": "string", "name": "string", "created_by": "integer" }

board_member_added

Disparado quando um membro é adicionado a um quadro branco.

{ "board_uuid": "string", "user_id": "integer", "role": "string" }

playground_created

Disparado quando um novo playground é criado.

{ "playground_uuid": "string", "name": "string", "created_by": "integer" }

Comunidade

discussion_posted

Disparado quando um usuário cria uma discussão.

{
  "user":       { "user_uuid": "string", "email": "string", "username": "string" },
  "discussion": { "discussion_uuid": "string", "title": "string" },
  "community":  { "community_uuid": "string" }
}

comment_created

Disparado quando um usuário publica um comentário em uma discussão.

{
  "user":       { "user_uuid": "string", "email": "string", "username": "string" },
  "comment":    { "comment_uuid": "string" },
  "discussion": { "discussion_uuid": "string", "title": "string" },
  "community":  { "community_uuid": "string" }
}

discussion_pinned

Disparado quando uma discussão é fixada ou desfixada.

{
  "discussion_uuid": "string",
  "title": "string",
  "is_pinned": "boolean",
  "community_uuid": "string"
}

discussion_locked

Disparado quando uma discussão é bloqueada ou desbloqueada.

{
  "discussion_uuid": "string",
  "title": "string",
  "is_locked": "boolean",
  "community_uuid": "string"
}

discussion_vote_cast

Disparado quando um usuário vota positivamente em uma discussão.

{ "discussion_uuid": "string", "user_id": "integer", "upvote_count": "integer" }

Grupos

usergroup_created

Disparado quando um novo grupo de usuários é criado.

{ "usergroup_uuid": "string", "name": "string" }

usergroup_deleted

Disparado quando um grupo de usuários é excluído.

{ "usergroup_uuid": "string", "name": "string" }

usergroup_users_added

Disparado quando usuários são adicionados a um grupo de usuários.

{
  "usergroup_id": "integer",
  "usergroup_uuid": "string",
  "user_ids": "list[integer]"
}

usergroup_resources_added

Disparado quando recursos são atribuídos a um grupo de usuários.

{
  "usergroup_id": "integer",
  "usergroup_uuid": "string",
  "resource_uuids": "list[string]"
}

Assinaturas

pack_activated

Disparado quando um pacote de assinatura é ativado.

{
  "pack_id": "string",

{

Organização

org_signup_method_changed

Disparado quando o mecanismo de cadastro da organização é alterado.

{ "signup_mechanism": "string" }

Disparado quando a configuração de IA da organização é atualizada.

{ "ai_enabled": "boolean", "copilot_enabled": "boolean" }

Disparado quando a configuração de pagamentos da organização é atualizada.

{ "payments_enabled": "boolean" }
