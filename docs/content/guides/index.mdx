# Guias

O resto da documentação explica *o que* o Notoriun é e *como cada recurso funciona*. **Guias**
são diferentes: cada um leva você até o fim de **construir algo real** com o Notoriun, de ponta a
ponta.

Todo guia é escrito para ser seguido do início ao fim, com comandos e código para copiar e
colar, e é testado contra uma instância real do Notoriun. Onde há um caminho mais rápido, você
terá uma escolha: fazer você mesmo, ou entregar o trabalho a um agente de código.

<GuideCards set="index" />

## O que você vai encontrar aqui

- **[Construir uma plataforma de aprendizado](/guides/build-learning-platform)** — Crie sua
  própria plataforma web de aprendizado em cima da API do Notoriun com Next.js. Você começa com
  um catálogo público totalmente anônimo, depois adiciona autenticação, matrícula, e
  rastreamento de progresso. Escolha o caminho **faça você mesmo** ou faça um **agente**
  construí-la a partir de uma especificação pronta.
- **[Recursos customizados e webhooks](/guides/custom-features)** — Vá além do frontend oficial:
  autentique com tokens de API, crie e consulte conteúdo programaticamente, e inscreva-se em
  webhooks para reagir à atividade de aprendizado em tempo real.

<Callout type="info">
Novo no Notoriun? Comece com o [Início Rápido](/getting-started/quickstart) para colocar uma
instância em execução, depois volte aqui para construir sobre ela. Os guias assumem que você tem
uma organização e ao menos um curso.
</Callout>

## Antes de começar

Estes guias interagem com a API REST do Notoriun, documentada em
[Desenvolvedores → Referência da API](/developers/api). Você vai aproveitar mais se estiver
confortável com:

- **HTTP e REST** — a API é uma API REST JSON padrão sob `/api/v1/`.
- **Uma instância do Notoriun em execução** — local ([self-hosting](/self-hosting)) ou na nuvem
  gerenciada. Os exemplos usam `http://localhost:1338` como base da API.
- **JavaScript / TypeScript** — o guia de construção usa Next.js, mas as chamadas de API são
  agnósticas de framework.
