# Construir uma Plataforma de Aprendizado

O Notoriun é **API-first**. O app web oficial é só um cliente de uma API REST pública — o que
significa que você pode construir sua *própria* plataforma de aprendizado em cima da mesma API,
com seu próprio design, seu próprio roteamento, e sua própria marca.

Este guia leva você de uma pasta vazia a uma **plataforma de aprendizado headless** funcionando:
um app Next.js que lista seus cursos, reproduz seu conteúdo, autentica usuários, os matricula, e
rastreia seu progresso — tudo alimentado pela API do Notoriun. É o tipo de resultado que você vai
encontrar no repositório [`notoriun/headless-examples`](https://github.com/notoriun/headless-examples).

## O que você vai construir

Uma plataforma de aprendizado que você alcança em dois estágios — **primeiro anônimo, depois
autenticado**. Você terá um site público funcionando antes mesmo de tocar em um único token.

<Tabs items={['Estágio 1 — Anônimo', 'Estágio 2 — Autenticado']}>
  <Tabs.Tab>
    Sem login, sem tokens. Só conteúdo público:
    - Um **catálogo de cursos** listando todo curso público na sua organização.
    - Uma **página de curso** mostrando capítulos e atividades.
    - Um **visualizador de atividade** que renderiza páginas dinâmicas, vídeos, e documentos.
  </Tabs.Tab>
  <Tabs.Tab>
    Colocado sobre o estágio 1, sem reescrevê-lo:
    - **Cadastro e login** com os endpoints de autenticação do Notoriun.
    - **Matrícula** — alunos entram em um curso.
    - **Rastreamento de progresso** — marca atividades como concluídas e mostra o quanto um
      aluno avançou.
  </Tabs.Tab>
</Tabs>

## Arquitetura

Seu app Next.js é um cliente fino e rápido na frente da API do Notoriun. Leituras acontecem em
**Server Components**; qualquer coisa envolvendo um token passa por um **Route Handler agindo
como um Backend-for-Frontend (BFF)**, então tokens do Notoriun nunca alcançam o navegador. A
mídia é transmitida diretamente do endpoint de entrega de conteúdo da API.

<HeadlessArchitecture />

<Callout type="info">
Usar um BFF do lado do servidor não é só para segurança — também evita o CORS por completo. Seu
navegador só fala com sua própria origem Next.js, e seu servidor fala com o Notoriun.
</Callout>

## Os recursos que você vai tocar

Tudo no Notoriun pende de uma **Organização**. Conteúdo é uma árvore de **Curso → Capítulo →
Atividade**. O progresso de um aluno é uma árvore separada: cada **Usuário** tem uma **Trilha**,
que contém uma **Execução (Run)** por curso matriculado, que contém um **Passo (Step)** por
atividade concluída.

<ResourceModelDiagram />

| Recurso | O que é | Endpoint principal |
| --- | --- | --- |
| Organização | Tenant de nível superior, endereçado por `org_slug` | `GET /api/v1/orgs/slug/{org_slug}` |
| Curso | Um curso, endereçado por `course_uuid` | `GET /api/v1/courses/org_slug/{org_slug}/page/{page}/limit/{limit}` |
| Capítulo + Atividade | A árvore de conteúdo do curso | `GET /api/v1/courses/{course_uuid}/meta` |
| Trilha / Execução / Passo | A matrícula e progresso de um aluno | `GET /api/v1/trail/org/{org_id}/trail` |

## Pré-requisitos

- **Node.js 18+** e um gerenciador de pacotes (`npm`, `pnpm`, ou `bun`).
- **Uma instância do Notoriun em execução.** Coloque uma no ar localmente com o
  [Início Rápido](/getting-started/quickstart) ou o [guia de self-hosting](/self-hosting). Os
  exemplos assumem que a API está em `http://localhost:1338`.
- **O slug da sua organização** e **ao menos um curso público e publicado** com algum conteúdo.
  Crie um no painel se ainda não tiver.
- Familiaridade básica com a [Referência da API](/developers/api).

<Callout type="warning">
Ao longo deste guia a URL base da API é `http://localhost:1338/api/v1`. Se sua instância está em
outro lugar (uma porta customizada ou um domínio), substitua pela sua própria URL base — todo
exemplo a lê de uma única variável de ambiente.
</Callout>
