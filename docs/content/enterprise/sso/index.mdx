# Single Sign-On (SSO)

O Notoriun suporta Single Sign-On empresarial, permitindo que organizações autentiquem usuários
através do seu provedor de identidade existente. Isso significa que usuários podem entrar com as
credenciais da empresa sem criar uma conta separada no Notoriun.

<Callout>
SSO exige um plano Enterprise.
</Callout>

## Provedores Suportados

| Provedor | Status | Descrição |
|---|---|---|
| [WorkOS](/enterprise/sso/workos) | Disponível | SSO empresarial com suporte a SAML e OIDC, inclui portal admin |
| [OIDC Customizado](/enterprise/sso/custom-oidc) | Disponível | Conecte qualquer provedor OpenID Connect (Azure AD, Okta, Google Workspace, Keycloak, etc.) |

<Callout type="info">
O provedor OIDC Customizado permite conectar-se a praticamente qualquer provedor de identidade
moderno que suporte OpenID Connect, incluindo Okta, Azure AD / Microsoft Entra ID, Google
Workspace, e Keycloak.
</Callout>

## Como o SSO Funciona

1. Um admin configura o SSO nas configurações da organização, selecionando um provedor e
   inserindo as credenciais necessárias.
2. Quando um usuário visita a página de login, ele vê uma opção de login SSO se o SSO estiver
   ativado para aquela organização.
3. Clicar no botão de SSO redireciona o usuário para a página de login do provedor de
   identidade.
4. Depois de autenticar com o IdP, o usuário é redirecionado de volta ao Notoriun com uma sessão
   ativa.

## Provisionamento de Usuário

Quando um usuário entra via SSO pela primeira vez, o Notoriun cria automaticamente sua conta
usando dados de perfil do provedor de identidade:

- **Nome, sobrenome, e e-mail** são mapeados do IdP.
- **Avatar** é importado se disponível.
- **Papel padrão** é atribuído com base na configuração de SSO (ex.: todos os novos usuários SSO
  recebem o papel `User`).

Usuários existentes cujo e-mail corresponde são vinculados automaticamente — nenhuma conta
duplicada é criada.

## Opções de Configuração

| Opção | Descrição |
|---|---|
| Provedor | Qual provedor de identidade usar (WorkOS ou OIDC Customizado). |
| Domínio de e-mail | Restringe o SSO a domínios de e-mail específicos. |
| Provisionamento automático | Cria automaticamente contas para novos usuários SSO. |
| Papel padrão | Papel atribuído a usuários recém-provisionados. |
| Portal admin | O WorkOS oferece um portal admin para gerenciar a conexão com o IdP diretamente. |
