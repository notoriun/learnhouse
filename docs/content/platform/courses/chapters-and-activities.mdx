# Capítulos e Atividades

Cursos no Notoriun seguem uma hierarquia clara: **Curso → Capítulos → Atividades**. Essa estrutura mantém o conteúdo organizado e dá aos alunos um caminho lógico pelo material.

## Capítulos

Capítulos são os agrupamentos de nível mais alto dentro de um curso. Use-os para dividir seu curso em módulos, unidades ou tópicos. Você pode reordenar capítulos em qualquer momento a partir do editor de curso.

## Atividades

Atividades são as peças individuais de conteúdo dentro de um capítulo. Cada atividade tem um tipo específico que determina como o conteúdo é apresentado aos alunos.

### Páginas Dinâmicas

Páginas dinâmicas usam o editor integrado baseado em blocos para criar conteúdo rico e interativo. Você pode combinar texto, imagens, blocos de código, callouts, embeds e muito mais em uma única página. Este é o tipo de atividade mais flexível.

### Vídeos

Atividades de vídeo permitem enviar arquivos de vídeo diretamente para o Notoriun ou embutir vídeos do YouTube e outras plataformas externas. Vídeos enviados são servidos pelo pipeline de mídia do Notoriun.

### Documentos

Atividades de documento exibem arquivos PDF usando um visualizador integrado. Envie um PDF e os alunos podem lê-lo diretamente na plataforma, sem precisar baixá-lo.

### Tarefas

Atividades de tarefa são trabalhos corrigíveis — atualmente uploads de arquivo e envios no estilo quiz. Professores podem corrigir envios pelo dashboard, e os resultados são registrados na [Trilha](/platform/courses/trails) do aluno. Veja [Tarefas](/platform/assignments) para detalhes sobre tipos de trabalho e correção.

### SCORM

Atividades SCORM embutem pacotes de aprendizagem SCORM 1.2 ou SCORM 2004. Este tipo de atividade faz parte da Edição Enterprise.

### Personalizado

Uma via de escape para implementações de atividade personalizadas, mantidas fora dos tipos integrados.

<Callout>
Quizzes estão disponíveis de duas formas: como um bloco de editor **Quiz** inline dentro de uma Página Dinâmica (verificações de conhecimento leves, sem correção) e como um **trabalho de Tarefa** (corrigível, com envios armazenados).
</Callout>

<Callout>
Você pode combinar diferentes tipos de atividade dentro de um mesmo capítulo para criar uma experiência de aprendizagem variada.
</Callout>
