# Cursos

Cursos são a unidade de conteúdo principal no Notoriun. Cada curso é composto por capítulos, e cada capítulo contém atividades que os alunos percorrem.

## Tipos de Atividade

O Notoriun suporta vários tipos de atividade para acomodar diferentes estilos de ensino:

- **Páginas dinâmicas** — Conteúdo WYSIWYG rico, construído com o editor baseado em blocos (quizzes e blocos de código podem ser embutidos inline).
- **Vídeos** — Envie arquivos de vídeo diretamente ou embuta do YouTube e outras fontes externas.
- **Documentos** — Documentos PDF exibidos com um visualizador integrado.
- **Tarefas** — Tarefas corrigíveis, como uploads de arquivo e quizzes. Veja [Tarefas](/platform/assignments).
- **SCORM** — Pacotes de aprendizagem SCORM 1.2 e SCORM 2004 (Edição Enterprise).
- **Personalizado** — Via de escape para implementações de atividade personalizadas.

## Primeiros Passos

Para criar um curso, navegue até o dashboard da sua organização e selecione **Criar Curso**. A partir daí você pode adicionar capítulos, preenchê-los com atividades e publicar quando estiver pronto.

<Callout>
Cursos podem ser agrupados em [Coleções](/platform/courses/collections) para melhor organização, e o progresso do aluno é acompanhado via [Trilhas](/platform/courses/trails).
</Callout>
