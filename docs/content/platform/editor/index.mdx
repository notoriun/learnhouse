# Editor

O Notoriun inclui um editor WYSIWYG baseado em blocos para criar conteúdo de curso. O editor oferece uma experiência ao estilo Notion, na qual você constrói páginas empilhando e organizando blocos de conteúdo.

## Principais Recursos

- **Edição baseada em blocos** — Cada peça de conteúdo (parágrafo, imagem, trecho de código) é um bloco independente que você pode mover, duplicar ou excluir.
- **Formatação rica** — Formatação de texto completa, incluindo negrito, itálico, links e código inline.
- **Arrastar e soltar** — Reorganize blocos arrastando-os para a posição desejada.
- **Comandos de barra** — Digite `/` para inserir rapidamente qualquer tipo de bloco.
