O editor do Notoriun suporta uma grande variedade de tipos de bloco para construir conteúdo de curso rico. Você pode inserir qualquer bloco digitando `/` e selecionando no menu.

## Usando Blocos

Cada bloco pode ser movido, duplicado ou excluído individualmente. Clique na alça do lado esquerdo de um bloco para arrastá-lo para uma nova posição, ou use o menu do bloco para opções adicionais.
