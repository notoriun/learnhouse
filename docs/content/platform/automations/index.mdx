# Automações

O Notoriun envia eventos em tempo real para os seus próprios sistemas e para ferramentas de automação no-code. Use-os para sincronizar alunos com o seu CRM, notificar um canal do Slack na conclusão de um curso, disparar a impressão de certificados, ou alimentar qualquer fluxo de trabalho posterior.

<Callout type="info">
Automações estão disponíveis no plano **Pro** ou superior. Tanto webhooks quanto Zapier dependem de tokens de API restritos a uma única organização.
</Callout>

## O que está disponível

- **[Webhooks](/platform/automations/webhooks)** — Entregas HTTP `POST` diretas e assinadas para qualquer URL que você controle. Ideal para backends próprios e serviços self-hosted.
- **[Zapier](/platform/automations/zapier)** — App oficial do Zapier, com triggers para cada evento do Notoriun e ações para matricular usuários, concluir atividades e buscar alunos. Ideal para fluxos no-code no Slack, Google Sheets, HubSpot e mais de 6.000 outros apps do Zapier.
- **[Catálogo de Eventos](/platform/automations/events)** — A lista canônica de todo evento que pode disparar, com os esquemas de payload.

## Como Funciona

Toda automação é alimentada pelo mesmo barramento de eventos interno:

1. Algo acontece dentro do Notoriun (um aluno conclui um curso, um usuário é convidado, uma tarefa é corrigida, …).
2. O evento é disparado para todo assinante ativo daquela organização — endpoints de webhook que você configurou manualmente, e qualquer assinatura de REST Hook do Zapier criada pelos seus Zaps ativos.
3. Cada endpoint recebe o mesmo envelope JSON, com um nome de evento, um ID de entrega, um ID de organização e um payload `data` específico do evento.

Assinatura, novas tentativas, logs de entrega e proteção contra SSRF funcionam de forma idêntica nos dois caminhos. Escolher entre webhooks e Zapier é uma questão de onde você quer tratar o evento, não de receber um payload diferente.

## Escolhendo entre Webhooks e Zapier

| Você quer… | Use |
| --- | --- |
| Chamar um backend próprio que você controla | **Webhooks** |
| Rotear eventos para Slack, Google Sheets, HubSpot, Airtable, Notion, etc. | **Zapier** |
| Verificar assinaturas criptográficas nos payloads | **Webhooks** (o Zapier trata sua própria autenticação internamente) |
| Executar uma **ação do Notoriun** a partir de outro app (ex.: matricular um usuário quando um formulário do HubSpot é enviado) | **Zapier** |
| Manter as dependências de infraestrutura no mínimo | **Webhooks** |

Você pode usar os dois ao mesmo tempo, para os mesmos eventos.
