# Busca

O Notoriun inclui um sistema de busca integrado que permite aos usuários encontrar cursos, coleções e outros usuários em toda a organização.

## Como a Busca Funciona

A busca é restrita à organização atual. Quando um usuário digita uma consulta, o sistema busca entre:

- **Cursos** — Corresponde por título, descrição e conteúdo do curso.
- **Coleções** — Encontra coleções por nome ou descrição.
- **Usuários** — Busca membros da organização por nome ou nome de usuário.

Os resultados são retornados com paginação, exibindo até 50 resultados por página.

## Recursos

- **Restrita à organização** — Os resultados de busca de cada organização são isolados, garantindo que os usuários vejam apenas conteúdo da própria organização.
- **Busca entre tipos de conteúdo** — Uma única consulta de busca retorna resultados entre múltiplos tipos de conteúdo.
- **Paginação** — Os resultados são paginados para uma navegação eficiente em conjuntos grandes de resultados.
