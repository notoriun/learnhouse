# Matrículas e Checkout

Matrículas acompanham o acesso do aluno a conteúdo pago. Quando um aluno completa uma compra, um registro de matrícula é criado, concedendo acesso aos cursos associados.

## Fluxo de Checkout

1. Um aluno seleciona uma oferta na vitrine ou na página do curso.
2. Ele é redirecionado para uma página de checkout hospedada pelo Stripe.
3. Após o pagamento ser confirmado, uma matrícula é criada automaticamente.
4. O aluno ganha acesso imediato aos cursos comprados.

## Status de Matrícula

| Status | Descrição |
|---|---|
| Pendente | Pagamento iniciado, mas ainda não confirmado. |
| Concluída | Pagamento único bem-sucedido, acesso concedido. |
| Ativa | Assinatura ativa, acesso concedido. |
| Cancelada | Assinatura cancelada, acesso revogado. |
| Falhou | Pagamento falhou. |
| Reembolsada | Pagamento reembolsado, acesso revogado. |

## Portal de Cobrança

Alunos com assinaturas ativas podem acessar um portal de cobrança do Stripe para gerenciar seus métodos de pagamento, ver faturas e cancelar ou atualizar suas assinaturas.

## Dashboard do Stripe

Administradores podem ver uma visão geral de cobranças, assinaturas e clientes diretamente do painel administrativo do Notoriun, sem precisar entrar no Stripe separadamente.
