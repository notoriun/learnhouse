# Grupos e Pacotes

Grupos permitem agrupar vários cursos e vendê-los como um único pacote. Quando um aluno compra uma oferta vinculada a um grupo, ele recebe acesso a todos os cursos daquele grupo.

## Como Grupos Funcionam

1. Crie um grupo e dê a ele um nome.
2. Adicione cursos ao grupo.
3. Vincule o grupo a uma ou mais ofertas.
4. Quando um aluno compra a oferta, ele é matriculado em todos os cursos dentro do grupo.

## Sincronização com Grupos de Usuários

Grupos podem ser sincronizados com grupos de usuários para provisionamento automático de acesso. Quando um grupo de pagamento é sincronizado com um grupo de usuários, os alunos que compram uma oferta vinculada a esse grupo são adicionados automaticamente ao grupo de usuários correspondente, ganhando acesso a todos os recursos associados.

## Vínculo Direto de Recurso

Se você não precisar de um grupo, também pode vincular cursos individuais diretamente a uma oferta. Isso é útil para vender cursos únicos sem criar um pacote.
