# Multi-Tenancy

<Callout type="warning">
Multi-tenancy é um recurso **Enterprise**. Não está disponível nos planos de código aberto ou padrão.
</Callout>

O Notoriun suporta rodar uma ou mais organizações em uma única instância. Essa arquitetura multi-tenant permite atender diferentes grupos a partir da mesma implantação.

## Organização Única (Padrão)

Por padrão, o Notoriun roda com uma única organização. Esta é a configuração mais simples, adequada para a maioria das implantações em que um único time, escola ou empresa usa a plataforma.

## Multi-Organização

No modo multi-org, uma única instância do Notoriun hospeda múltiplas organizações independentes. Cada organização opera como se fosse sua própria plataforma separada:

- Cursos, usuários e configurações são totalmente restritos a cada organização.
- Os dados são armazenados em um banco compartilhado, mas isolados por ID de organização.
- Cada organização pode ter sua própria identidade visual e configuração.

<Callout>
O modo multi-org é útil para plataformas que atendem múltiplas escolas, departamentos ou clientes a partir de uma implantação centralizada.
</Callout>

## Isolamento de Dados

Todas as consultas ao banco de dados são restritas por `org_id`, garantindo que uma organização não possa acessar os dados de outra. Usuários, cursos, coleções, trilhas e configurações são todos particionados no nível da organização.
