# Organizações

Organizações são o tenant de nível mais alto no Notoriun. Todo conteúdo, todo usuário e toda configuração pertencem a uma organização.

## O Que Uma Organização Contém

Cada organização tem seus próprios:

- **Cursos e coleções** — Todo conteúdo educacional pertence à organização.
- **Usuários** — Membros pertencem a uma organização e recebem papéis dentro dela.
- **Configurações** — Identidade visual, configuração de IA, regras de cadastro e mais são configuradas por organização.
