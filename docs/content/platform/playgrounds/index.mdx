# Playgrounds

Playgrounds são **experiências HTML interativas geradas por IA** que professores podem publicar junto aos seus cursos. Não são um executor de código multi-linguagem — para isso, use o [bloco de editor Playground de Código](/platform/code-execution).

<Callout>
Playgrounds precisam estar habilitados nas [Configurações da Organização](/platform/organizations/settings) para ficarem disponíveis. A IA também precisa estar habilitada na instância (veja [Configuração de IA](/self-hosting/configuration/ai-setup)).
</Callout>

## Como Playgrounds Funcionam

Um playground é um artefato HTML/JS interativo gerado pelo Google Gemini a partir de um prompt em linguagem natural. Professores descrevem o que querem — uma visualização, uma simulação, um exercício interativo — e o Notoriun armazena o HTML resultante junto ao restante do material do curso.

Cada playground suporta até 10 refinamentos iterativos, então professores podem ajustar prompts e regenerar sem começar do zero.

## Principais Recursos

- **Geração guiada por IA** — Peça ao Gemini para produzir experiências HTML interativas personalizadas.
- **Iteração** — Refine um playground até 10 vezes; cada versão é rastreada.
- **Controle de acesso** — Cada playground tem um de três modos de acesso: `PUBLIC`, `AUTHENTICATED` ou `RESTRICTED` (limitado a grupos de usuários específicos).
- **Reações** — Usuários podem reagir a playgrounds para dar feedback.

## Casos de Uso

- **Simulações personalizadas** — Gere visualizações de física, matemática ou química sob demanda.
- **Exemplos interativos** — Publique widgets práticos que reforcem o material de leitura.
- **Prototipagem de atividades** — Explore rapidamente ideias de ensino antes de construí-las como atividades completas.

## Playgrounds vs Playground de Código (bloco de editor)

São dois recursos distintos que compartilham o nome:

| Recurso | Propósito | Motor |
| --- | --- | --- |
| **Playgrounds** (esta página) | Experiências HTML interativas geradas por IA | Google Gemini |
| Bloco de editor **Playground de Código** | Bloco multi-linguagem "execute este código" dentro de atividades de Página Dinâmica | Judge0 (veja [Execução de Código](/platform/code-execution)) |
