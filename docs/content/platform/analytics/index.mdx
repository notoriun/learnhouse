# Analytics

O Notoriun oferece analytics para ajudar administradores e professores a entender como os alunos interagem com o conteúdo. O Analytics acompanha atividade do usuário, engajamento com cursos e uso da plataforma.

<Callout>
Analytics precisa estar habilitado nas [Configurações da Organização](/platform/organizations/settings) para ficar disponível.
</Callout>

## O Que É Acompanhado

- **Engajamento do usuário** — Visualizações de atividade, tempo gasto e padrões de interação.
- **Analytics de curso** — Quais cursos e atividades são mais populares e como os alunos progridem por eles.
- **Métricas no nível da organização** — Tendências gerais de uso e crescimento da plataforma.

## Como o Analytics Funciona

Eventos são registrados conforme os usuários interagem com a plataforma — visualizando atividades, concluindo cursos, enviando tarefas, e mais. Esses eventos são agregados em dashboards acessíveis pelo painel administrativo.

## Acessando o Analytics

Administradores podem acessar o dashboard global de analytics pelo painel administrativo da organização. Os dados de analytics são restritos à organização atual, então cada organização vê apenas seus próprios dados.

<Callout>
O Analytics usa cache de eventos para desempenho. Os dados podem levar um pequeno tempo para refletir a atividade mais recente.
</Callout>
