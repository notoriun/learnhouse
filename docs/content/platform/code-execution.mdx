# Execução de Código

O Notoriun se integra ao [Judge0](https://judge0.com/) para oferecer execução de código em sandbox dentro de blocos **Playground de Código** em atividades de Página Dinâmica. Alunos podem escrever e executar código diretamente na plataforma, e professores podem definir casos de teste para correção automática.

## Linguagens Suportadas

O bloco Playground de Código suporta 30 linguagens: Python 3, JavaScript (Node), TypeScript, Java, C, C++, Rust, Go, PHP, Ruby, Kotlin, C#, Swift, Scala, Perl, R, Dart, Haskell, Lua, Elixir, Clojure, SQL, Bash, Objective-C, Pascal, Fortran, Prolog, Common Lisp, PowerShell e Assembly (NASM).

## Como Funciona

1. Um professor insere um bloco **Playground de Código** em uma atividade de Página Dinâmica e (opcionalmente) define casos de teste como pares de entrada/saída.
2. Alunos escrevem sua solução no editor de código integrado, embutido na atividade.
3. No envio, o código é executado contra todos os casos de teste em um ambiente Judge0 isolado.
4. Os resultados são reportados por caso de teste — passou/falhou, tempo de execução e uso de memória. Os envios são armazenados por `activity_uuid` + `block_id`.

<Callout type="info">
Execução de código aparece como um bloco de editor dentro do conteúdo do curso — **não** é um tipo de subtrabalho de tarefa independente. Se você quiser exercícios de código corrigíveis, insira um bloco Playground de Código em uma atividade de Página Dinâmica.
</Callout>

## Casos de Teste

Cada caso de teste define:

- **Entrada** — A entrada padrão fornecida ao programa.
- **Saída Esperada** — A saída que o programa deve produzir.

O sistema executa o código do aluno contra cada caso de teste e compara a saída real com a saída esperada.

<Callout>
Execução de código exige uma instância do Judge0 configurada. Veja a [Configuração de Self-Hosting](/self-hosting/configuration) para detalhes.
</Callout>

## Execução em Lote

Para blocos com múltiplos casos de teste, a plataforma executa todos os casos de teste em uma única requisição em lote, oferecendo um resumo completo dos resultados que mostra quais testes passaram e quais falharam.
