# Variáveis de Ambiente

A CLI gera um arquivo `.env` durante a instalação com todas as variáveis de configuração. Elas
também podem ser editadas interativamente com `npx learnhouse env`.

## Domínio e Hospedagem

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `LEARNHOUSE_DOMAIN` | Hostname | `localhost` |
| `HTTP_PORT` | Porta HTTP para o proxy reverso | `80` |
| `NEXT_PUBLIC_LEARNHOUSE_API_URL` | URL pública da API | `http://localhost/api/v1/` |
| `NEXT_PUBLIC_LEARNHOUSE_BACKEND_URL` | URL do backend | `http://localhost` |
| `NEXT_PUBLIC_LEARNHOUSE_DOMAIN` | Domínio público | `localhost` |
| `NEXT_PUBLIC_LEARNHOUSE_TOP_DOMAIN` | Domínio de nível superior | `localhost` |
| `NEXT_PUBLIC_LEARNHOUSE_MULTI_ORG` | Modo multi-organização | `false` |
| `NEXT_PUBLIC_LEARNHOUSE_DEFAULT_ORG` | Slug da organização padrão | `my-school` |
| `NEXT_PUBLIC_LEARNHOUSE_HTTPS` | HTTPS ativado | `false` |

## Banco de Dados e Redis

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `LEARNHOUSE_SQL_CONNECTION_STRING` | Conexão PostgreSQL | `postgresql://learnhouse:pass@db:5432/learnhouse` |
| `LEARNHOUSE_REDIS_CONNECTION_STRING` | Conexão Redis | `redis://redis:6379/learnhouse` |
| `LEARNHOUSE_REDIS_URL` | URL do Redis | `redis://redis:6379/learnhouse` |
| `POSTGRES_USER` | Usuário do banco de dados (só local) | `learnhouse` |
| `POSTGRES_PASSWORD` | Senha do banco de dados (só local) | Gerada automaticamente |
| `POSTGRES_DB` | Nome do banco de dados (só local) | `learnhouse` |

## Segurança e Autenticação

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `LEARNHOUSE_AUTH_JWT_SECRET_KEY` | Chave de assinatura JWT | Gerada automaticamente |
| `LEARNHOUSE_INITIAL_ADMIN_EMAIL` | E-mail do primeiro admin | `admin@example.com` |
| `LEARNHOUSE_INITIAL_ADMIN_PASSWORD` | Senha do primeiro admin | Definida durante a instalação |
| `LEARNHOUSE_COOKIE_DOMAIN` | Domínio de cookie | `localhost` |
| `COLLAB_INTERNAL_KEY` | Chave do serviço de colaboração | Gerada automaticamente |
| `NEXTAUTH_SECRET` | Segredo do NextAuth | Gerado automaticamente |
| `NEXTAUTH_URL` | URL do NextAuth | `http://localhost` |

## Aplicação

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `LEARNHOUSE_PORT` | Porta interna da API | `9000` |
| `LEARNHOUSE_DEVELOPMENT_MODE` | Flag de modo de desenvolvimento | `False` |
| `NEXT_PUBLIC_COLLAB_URL` | URL WebSocket do collab | `ws://localhost/collab` |

## IA

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `LEARNHOUSE_IS_AI_ENABLED` | Ativa recursos de IA | `True` / `False` |
| `LEARNHOUSE_GEMINI_API_KEY` | Chave de API do Gemini | Sua chave de API |

## E-mail

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `LEARNHOUSE_EMAIL_PROVIDER` | Provedor de e-mail | `resend` / `smtp` |
| `LEARNHOUSE_SYSTEM_EMAIL_ADDRESS` | Endereço remetente | `noreply@example.com` |
| `LEARNHOUSE_RESEND_API_KEY` | Chave de API do Resend | Sua chave de API |
| `LEARNHOUSE_SMTP_HOST` | Host SMTP | `smtp.gmail.com` |
| `LEARNHOUSE_SMTP_PORT` | Porta SMTP | `587` |
| `LEARNHOUSE_SMTP_USERNAME` | Usuário SMTP | `user@example.com` |
| `LEARNHOUSE_SMTP_PASSWORD` | Senha SMTP | Sua senha |
| `LEARNHOUSE_SMTP_USE_TLS` | Ativa TLS | `True` / `False` |

## Armazenamento S3

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `LEARNHOUSE_CONTENT_DELIVERY_TYPE` | Tipo de armazenamento | `filesystem` / `s3api` |
| `LEARNHOUSE_S3_API_BUCKET_NAME` | Nome do bucket S3 | `my-bucket` |
| `LEARNHOUSE_S3_API_ENDPOINT_URL` | Endpoint S3 (opcional para AWS) | `https://s3.amazonaws.com` |

## OAuth

| Variável | Descrição | Exemplo |
| --- | --- | --- |
| `LEARNHOUSE_GOOGLE_CLIENT_ID` | ID de client do Google OAuth | Seu ID de client |
| `LEARNHOUSE_GOOGLE_CLIENT_SECRET` | Segredo de client do Google OAuth | Seu segredo |

| Variável | Descrição | Exemplo |
