# CLI

A CLI do Notoriun é a ferramenta principal para implantar, gerenciar e desenvolver o Notoriun.
Ela orquestra serviços do Docker Compose e fornece um assistente de instalação interativo para
implantações de produção, além de um ambiente de desenvolvimento local completo.

**Pacote**: [`learnhouse`](https://www.npmjs.com/package/learnhouse) no npm

## Instalação

### Início Rápido (recomendado)

```bash
npx learnhouse@latest setup
```

### Instalação em Uma Linha (macOS / Linux)

Instala o Docker, o Node.js, e inicia a CLI:

```bash
curl -fsSL https://raw.githubusercontent.com/notoriun/learnhouse/main/apps/cli/install.sh | bash
```

### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/notoriun/learnhouse/main/apps/cli/install.ps1 | iex
```

## Requisitos

- **Node.js** 18+
- **Docker** com Docker Compose v2

## O Que Ela Faz

A CLI lida com dois fluxos de trabalho principais:

### Implantação de Produção

O [assistente de instalação](/cli/setup-wizard) gera uma implantação Docker Compose completa
com:

- Contêiner da **aplicação Notoriun** (Next.js + FastAPI)
- Banco de dados **PostgreSQL** (com pgvector opcional para IA)
- Cache **Redis**
- Proxy reverso **Caddy** ou **Nginx** (com auto-SSL opcional)

Cada implantação recebe um ID único, permitindo múltiplas instâncias na mesma máquina.

### Desenvolvimento Local

O [comando `dev`](/cli/dev-mode) inicia a infraestrutura no Docker e executa os servidores de
API, web, e colaboração localmente com hot reload.

## Referência Rápida

| Comando | Descrição |
| --- | --- |
| `npx learnhouse setup` | Assistente de instalação interativo |
| `npx learnhouse start` | Inicia todos os serviços |
| `npx learnhouse stop` | Para todos os serviços |
| `npx learnhouse update` | Atualiza para a versão mais recente ou uma específica |
| `npx learnhouse status` | Mostra o status dos serviços |
| `npx learnhouse health` | Executa verificações de saúde |
| `npx learnhouse logs` | Acompanha os logs dos contêineres |
| `npx learnhouse config` | Mostra informações da instalação |
| `npx learnhouse env` | Edita variáveis de ambiente |
| `npx learnhouse backup` | Faz backup do banco de dados |
| `npx learnhouse restore <archive>` | Restaura o banco de dados a partir de um backup |
| `npx learnhouse doctor` | Executa diagnósticos |
| `npx learnhouse deployments` | Gerencia implantações e limites de recursos |
| `npx learnhouse shell` | Abre um shell em um contêiner |
| `npx learnhouse dev` | Inicia o ambiente de desenvolvimento |
