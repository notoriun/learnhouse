# Modo de Desenvolvimento

O comando `dev` inicia um ambiente de desenvolvimento local completo com hot reload para todos
os serviços.

```bash
npx learnhouse dev
```

## Como Funciona

O comando divide infraestrutura e serviços de aplicação:

- **Infraestrutura** (Docker): PostgreSQL com pgvector + Redis rodam em contêineres via
  `.learnhouse/docker-compose.dev.yml`
- **Aplicação** (local): Os servidores de API, Web, e Collab rodam diretamente na sua máquina
  com hot reload

## Requisitos

- Docker (para banco de dados e Redis)
- [bun](https://bun.sh/) (para dependências de web e collab)
- [uv](https://docs.astral.sh/uv/) (para dependências da API Python)

<Callout type="warning">
`bun` e `uv` devem ser instalados previamente. A CLI executa `bun install` e `uv sync` para
instalar as dependências do projeto, mas não instala os próprios gerenciadores de pacotes.
</Callout>

## Fluxo de Inicialização

1. **Detecta a raiz do projeto** — Procura pela estrutura do monorepo (`apps/api`, `apps/web`,
   `apps/collab`)
2. **Inicia a infraestrutura** — Lança os contêineres do PostgreSQL e Redis (reutiliza os
   existentes se já estiverem em execução)
3. **Verificações de saúde** — Espera o banco de dados e o Redis estarem prontos
4. **Configuração do admin** — Quando os contêineres de banco de dados e Redis são criados por
   pela primeira vez, pergunta por um e-mail e senha de admin. Em execuções subsequentes com
   contêineres já existentes, o prompt é pulado e as credenciais existentes permanecem válidas.
   Você também pode passar `--admin-email` e `--admin-password` para pular o prompt.
5. **Instala dependências** — Executa `bun install` e `uv sync` se necessário
6. **Inicia os serviços** — Lança API, Web, e Collab com saída colorida

## Serviços

| Serviço | Comando | Porta |
| --- | --- | --- |
| API | `uv run python app.py` | 1338 |
| Web | `next dev --turbopack` | 3000 |
| Collab | `tsx watch src/index.ts` | 4000 |

## Controles Interativos

Enquanto está em execução, você pode digitar comandos para gerenciar os serviços:

| Tecla | Ação |
| --- | --- |
| `ra` | Reinicia a API |
| `rw` | Reinicia o Web |
| `rc` | Reinicia o Collab |
| `rb` | Reinicia todos os serviços |
| `q` | Sai (encerramento gracioso) |

## Edição Enterprise

Use a flag `--ee` para ativar os recursos da Edição Enterprise:

```bash
npx learnhouse dev --ee
```

Sem a flag, o diretório `apps/api/ee/` é temporariamente escondido durante o desenvolvimento.

## Encerramento

Quando você sai (`q` ou Ctrl+C):

- Os serviços locais (API, Web, Collab) são parados
- Os contêineres Docker (PostgreSQL, Redis) continuam em execução para a próxima sessão
- Para parar totalmente a infraestrutura:

```bash
docker compose -f .learnhouse/docker-compose.dev.yml -p learnhouse-dev down
```

<Callout type="info">
Os dados do banco de dados persistem entre sessões de dev via volumes Docker. Seus dados estão
seguros entre reinícios.
</Callout>
