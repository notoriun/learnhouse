# Assistente de Instalação

O assistente de instalação (`npx learnhouse@latest setup`) é um processo interativo de 6 passos
que gera uma implantação Docker Compose completa. Você pode voltar e editar qualquer passo antes
de confirmar.

## Passo 1 — Diretório de Instalação

Escolha onde os arquivos de implantação serão criados.

- **Padrão**: `./learnhouse`
- O diretório é criado se não existir

## Passo 2 — Configuração de Domínio

Configure seu hostname e as configurações de HTTPS.

- **Domínio**: hostname ou endereço IP (padrão: `localhost`)
- **Opções de HTTPS** (só para não-localhost):
  - **SSL Automático** (recomendado) — Usa Let's Encrypt via Caddy. Requer um domínio válido e
    as portas 80/443.
  - **SSL Manual** — Você lida com o proxy reverso ou o Cloudflare. O Notoriun roda em HTTP
    internamente.
  - **Sem HTTPS** — Só HTTP (não recomendado para produção)
- **Porta**: Definida automaticamente com base na escolha de SSL (443 para SSL automático, 80
  para HTTP)

## Passo 3 — Banco de Dados e Redis

Escolha contêineres Docker locais ou conecte-se a serviços externos.

### PostgreSQL

- **Docker local** (recomendado):
  - Usa `pgvector/pgvector:pg16` (PostgreSQL 16 com a extensão pgvector, usada para recursos de
    IA/RAG quando ativados)
  - A senha é gerada automaticamente
- **Externo** — Forneça uma string de conexão (`postgresql://user:pass@host:5432/db`). O
  assistente testa a conectividade antes de continuar.

### Redis

- **Docker local** (recomendado) — Usa `redis:7.2.3-alpine`
- **Externo** — Forneça uma string de conexão. O assistente testa a conectividade antes de
  continuar.

## Passo 4 — Organização

Defina o nome da sua organização (ex.: "Minha Escola"). Isso cria a organização inicial no
banco de dados.

## Passo 5 — Conta de Admin

Crie o primeiro usuário admin com e-mail e senha (mínimo de 8 caracteres).

## Passo 6 — Recursos Opcionais

Ative qualquer uma das seguintes integrações:

| Recurso | Configuração Necessária |
| --- | --- |
| **IA (Gemini)** | Chave de API do Gemini |
| **E-mail (Resend)** | Chave de API do Resend + endereço de e-mail do sistema |
| **E-mail (SMTP)** | Host, porta, usuário, senha, toggle de TLS + e-mail do sistema |
| **Armazenamento S3** | Nome do bucket, URL do endpoint (opcional para AWS) |
| **Google OAuth** | Client ID + Client Secret |
| **Unsplash** | Chave de Acesso |

## Confirmação

Depois de completar todos os passos, o assistente mostra um resumo da sua configuração. Você
pode:

- **Continuar** — Gerar os arquivos e opcionalmente iniciar a implantação
- **Editar** — Voltar e mudar qualquer passo
- **Cancelar** — Abortar sem gerar nada

## Arquivos Gerados

Depois da confirmação, o assistente cria:

```
{installDir}/
├── docker-compose.yml        # Definições de serviço
├── .env                      # Todas as variáveis de configuração
├── learnhouse.config.json    # Metadados da CLI
└── extra/
    ├── Caddyfile             # Se auto-SSL ativado
    └── nginx.prod.conf       # Se SSL manual ou HTTP
```

## Serviços Docker

Cada implantação recebe um ID único de 8 caracteres para isolamento de contêiner e rede.

| Serviço | Imagem | Propósito |
| --- | --- | --- |
| `learnhouse-app-{id}` | `ghcr.io/notoriun/learnhouse/app:latest` (ou `:dev`) | Aplicação Next.js + FastAPI |
| `learnhouse-db-{id}` | `pgvector/pgvector:pg16` | Banco de dados PostgreSQL |
| `learnhouse-redis-{id}` | `redis:7.2.3-alpine` | Cache Redis |
| `learnhouse-caddy-{id}` | `caddy:2-alpine` | Proxy reverso com auto-SSL |
| `learnhouse-nginx-{id}` | `nginx:alpine` | Proxy reverso (sem auto-SSL) |

<Callout type="info">
O assistente opcionalmente inicia a implantação e espera até 3 minutos pela verificação de
saúde (`/api/v1/health`) passar antes de mostrar suas credenciais e URL.
</Callout>

## Canais de Release

Durante a instalação você escolhe um canal de release:

- **Stable** — Recomendado para produção (baixa `ghcr.io/notoriun/learnhouse/app:latest`)
- **Dev** — Últimas novidades, recursos mais recentes (baixa
  `ghcr.io/notoriun/learnhouse/app:dev`)

Para fixar em uma tag de imagem específica após a instalação, use
`learnhouse update --version <tag>`.
