# Self-Hosting do Notoriun

O Notoriun pode ser self-hosted na sua própria infraestrutura usando a **CLI do Notoriun**. A CLI cuida de tudo, desde a configuração inicial até a manutenção contínua, incluindo geração de Docker Compose, gestão de arquivo de ambiente, orquestração de serviços, backups e verificações de saúde.

## Primeiros Passos Rápidos

Certifique-se de ter **Docker Engine 20.10+**, **Docker Compose 2.0+** e **Node.js 18+** instalados, depois execute:

```bash
npx learnhouse@latest setup
```

O assistente interativo de instalação vai conduzi-lo pela configuração de domínio, definições do banco de dados, credenciais de administrador e recursos opcionais. Ao concluir, inicie todos os serviços:

```bash
npx learnhouse start
```

O Notoriun estará disponível em **http://localhost** (ou no seu domínio configurado). Entre com as credenciais de administrador fornecidas durante a instalação.

<Callout type="info">
A CLI gera `docker-compose.yml`, `.env` e a configuração de proxy reverso para você. Você não precisa escrever ou manter esses arquivos manualmente.
</Callout>

### Verifique a instalação

```bash
npx learnhouse doctor
```

### Comandos de gestão comuns

```bash
npx learnhouse stop       # Para todos os serviços
npx learnhouse start      # Inicia todos os serviços
npx learnhouse logs       # Acompanha os logs dos contêineres
npx learnhouse config     # Vê a configuração atual
npx learnhouse backup     # Faz backup ou restaura o banco de dados
npx learnhouse doctor     # Diagnostica problemas
```
