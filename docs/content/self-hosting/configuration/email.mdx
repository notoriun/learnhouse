# Configuração de E-mail

O Notoriun suporta dois provedores de e-mail para entrega de e-mails transacionais: **Resend** e
**SMTP**. O e-mail é usado para convites de usuário, redefinição de senha e notificações do
sistema.

## Escolhendo um Provedor

Defina o provedor de e-mail no seu arquivo `.env` usando a variável `LEARNHOUSE_EMAIL_PROVIDER`:

```env
LEARNHOUSE_EMAIL_PROVIDER=resend   # ou "smtp"
```

## Opção 1: Resend

[Resend](https://resend.com) é um serviço de API de e-mail amigável para desenvolvedores.

```env
LEARNHOUSE_EMAIL_PROVIDER=resend
LEARNHOUSE_RESEND_API_KEY=re_your-resend-api-key
LEARNHOUSE_SYSTEM_EMAIL_ADDRESS=noreply@example.com
```

### Obtendo uma Chave de API do Resend

1. Crie uma conta em [resend.com](https://resend.com)
2. Adicione e verifique seu domínio de envio
3. Gere uma chave de API no painel do Resend
4. Copie a chave de API para o seu arquivo `.env`

## Opção 2: SMTP

Você pode usar qualquer servidor SMTP, incluindo serviços como Amazon SES, Mailgun, ou seu
próprio servidor de e-mail.

```env
LEARNHOUSE_EMAIL_PROVIDER=smtp
LEARNHOUSE_SMTP_HOST=smtp.example.com
LEARNHOUSE_SMTP_PORT=587
LEARNHOUSE_SMTP_USERNAME=user@example.com
LEARNHOUSE_SMTP_PASSWORD=your-smtp-password
LEARNHOUSE_SMTP_USE_TLS=true
LEARNHOUSE_SYSTEM_EMAIL_ADDRESS=noreply@example.com
```

### Variáveis SMTP

| Variável | Descrição | Padrão |
|---|---|---|
| `LEARNHOUSE_SMTP_HOST` | Hostname do servidor SMTP | -- |
| `LEARNHOUSE_SMTP_PORT` | Porta do servidor SMTP | `587` |
| `LEARNHOUSE_SMTP_USERNAME` | Usuário de autenticação SMTP | -- |
| `LEARNHOUSE_SMTP_PASSWORD` | Senha de autenticação SMTP | -- |
| `LEARNHOUSE_SMTP_USE_TLS` | Ativa criptografia TLS | `true` |

## Aplicando Mudanças

Depois de atualizar sua configuração de e-mail, reinicie sua instância:

```bash
learnhouse stop
learnhouse start
```

## Endereço de E-mail do Sistema

O `LEARNHOUSE_SYSTEM_EMAIL_ADDRESS` é o endereço "de" usado para todos os e-mails enviados. Ao
usar o Resend, esse endereço deve pertencer a um domínio verificado na sua conta Resend. Ao usar
SMTP, garanta que o endereço seja permitido pelo seu servidor SMTP.

<Callout type="info">
Se o e-mail não estiver configurado, recursos como convites de usuário e redefinição de senha não
vão funcionar. Usuários ainda podem ser criados manualmente por um administrador.
</Callout>

## Quais E-mails São Enviados

O Notoriun envia os seguintes tipos de e-mail:

- **Convites de usuário** -- quando um admin convida um usuário para entrar na plataforma ou em
  uma organização
- **Redefinição de senha** -- quando um usuário solicita uma redefinição de senha
- **Notificações do sistema** -- notificações importantes de nível de sistema
