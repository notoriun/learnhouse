# Configuração de SSL e Domínio

Proteger sua instância do Notoriun com SSL é fortemente recomendado para implantações de
produção. Este guia cobre a configuração de domínio e as opções de configuração de SSL.

## Configuração de Domínio

Defina seu domínio no arquivo `.env`:

```env
LEARNHOUSE_DOMAIN=learn.example.com
LEARNHOUSE_SSL=true
LEARNHOUSE_COOKIE_DOMAIN=.example.com
```

Certifique-se de que seus registros DNS apontam para o servidor que executa o Notoriun antes de
ativar o SSL.

## Usando um Proxy Reverso

A abordagem recomendada para terminação SSL é colocar um proxy reverso na frente do Notoriun.
Isso te dá flexibilidade no gerenciamento de certificados e permite servir outras aplicações no
mesmo servidor.

### Caddy

O Caddy obtém e renova certificados Let's Encrypt automaticamente. Crie um `Caddyfile`:

```
learn.example.com {
    reverse_proxy localhost:80
}
```

### Nginx

Um exemplo de configuração do nginx com Let's Encrypt (via Certbot):

```nginx
server {
    listen 443 ssl;
    server_name learn.example.com;

    ssl_certificate /etc/letsencrypt/live/learn.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/learn.example.com/privkey.pem;

    location / {
        proxy_pass http://localhost:80;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

server {
    listen 80;
    server_name learn.example.com;
    return 301 https://$server_name$request_uri;
}
```

### Traefik

Se você usa o Traefik como seu proxy reverso, você pode configurá-lo para rotear tráfego para o
Notoriun e lidar com certificados Let's Encrypt automaticamente através do seu suporte ACME
integrado.

## Let's Encrypt

Para certificados SSL gratuitos e automatizados, use o Let's Encrypt com uma das opções de proxy
reverso acima:

- O **Caddy** lida com Let's Encrypt automaticamente, sem nenhuma configuração.
- O **Nginx** funciona com o [Certbot](https://certbot.eff.org/) para emissão e renovação
  automatizada de certificados.
- O **Traefik** tem suporte integrado a ACME/Let's Encrypt.

<Callout type="warning">
Ao ativar SSL, atualize toda a configuração relacionada para usar URLs `https://`, incluindo
`LEARNHOUSE_ALLOWED_ORIGINS` e `NEXTAUTH_URL`.
</Callout>

## Domínio de Cookie

A variável `LEARNHOUSE_COOKIE_DOMAIN` controla a qual domínio os cookies pertencem. Isso é
importante para que a autenticação funcione corretamente.

- Para um único domínio como `learn.example.com`, defina-o como `.example.com`
- Usar um ponto inicial (`.example.com`) permite que os cookies funcionem entre subdomínios, o
  que é necessário se você usar o modo multi-organização com subdomínios
