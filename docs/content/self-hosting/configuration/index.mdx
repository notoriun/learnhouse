# Visão Geral da Configuração

O Notoriun usa variáveis de ambiente como seu método principal de configuração. Quando você executa `learnhouse setup`, a CLI gera um arquivo `.env` com todas as variáveis necessárias, com base nas suas escolhas.

## Métodos de Configuração

O Notoriun suporta dois métodos de configuração:

1. **Variáveis de ambiente** (via arquivo `.env`) -- o método principal e recomendado
2. **Arquivo de configuração** (`config.yaml`) -- uma alternativa para usuários avançados

<Callout type="info">
Se ambos estiverem presentes, as variáveis de ambiente sempre têm precedência sobre os valores definidos no `config.yaml`.
</Callout>

## Editando a Configuração

Você pode modificar sua configuração em qualquer momento usando a CLI:

```bash
learnhouse config --edit
```

Alternativamente, edite o arquivo `.env` diretamente e reinicie os serviços:

```bash
learnhouse restart
```
