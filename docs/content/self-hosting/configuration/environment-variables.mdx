# Variáveis de Ambiente

Esta página é a referência de implantação para as variáveis de ambiente do Notoriun. O backend
carrega `apps/api/config/config.yaml` primeiro, depois sobrescreve as configurações
correspondentes a partir do ambiente. O app web lê valores `NEXT_PUBLIC_*` da configuração em
tempo de execução ou de `process.env`. O arquivo `.env` gerado pela CLI é a forma recomendada de
configurar uma instância self-hosted.

<Callout type="info">
Valores marcados como "obrigatório" não têm um valor padrão seguro para produção. Valores
marcados como "não definido" são opcionais: o recurso permanece desativado ou usa um valor de
fallback em tempo de execução quando a variável está ausente.
</Callout>

## Variáveis geradas relacionadas

Estas variáveis não usam o prefixo `LEARNHOUSE_`, mas a CLI as grava no mesmo arquivo `.env`, e
vários serviços as exigem.

| Variável | Descrição | Tipo | Padrão / obrigatório | Usado por |
| --- | --- | --- | --- | --- |
| `HTTP_PORT` | Porta HTTP pública escolhida durante a instalação via CLI. | número inteiro | escolha da instalação | Compose gerado pela CLI |
| `NEXTAUTH_URL` | URL base para os helpers de autenticação compatíveis com NextAuth. | URL | gerada a partir do domínio configurado | CLI, doctor |
| `NEXTAUTH_SECRET` | Segredo usado pelos helpers de autenticação compatíveis com NextAuth. | string secreta | gerado pela instalação via CLI | CLI, doctor |
| `COLLAB_INTERNAL_KEY` | Chave compartilhada para autenticação interna API-para-servidor-de-colaboração. | string secreta | obrigatório para autenticação de collab em dev e produção | API, Collab, CLI |
| `NEXT_PUBLIC_COLLAB_URL` | URL WebSocket pública para o servidor de colaboração. | URL WebSocket | gerada a partir do domínio configurado | Web, CLI |
| `COLLAB_PORT` | Porta local do servidor de colaboração. | número inteiro | `4000` no verificador de dev local | Collab, CLI de dev |
| `COLLAB_TRUST_PROXY` | Defina como `true` quando o servidor de colaboração rodar detrás de um proxy reverso, para que IPs de cliente (usados na limitação de taxa de WebSocket) sejam lidos de `X-Forwarded-For`. | booleano | `false` | Collab |
| `POSTGRES_USER` | Usuário do PostgreSQL para instalações de banco de dados não-externo geradas. | string | `learnhouse` | Compose gerado pela CLI |
| `POSTGRES_PASSWORD` | Senha do PostgreSQL para instalações de banco de dados não-externo geradas. | string secreta | gerada pela instalação via CLI | Compose gerado pela CLI |
| `POSTGRES_DB` | Nome do banco de dados PostgreSQL para instalações de banco de dados não-externo geradas. | string | `learnhouse` | Compose gerado pela CLI |

## Exemplo completo

```env filename=".env" copy
# Domínio e hospedagem
LEARNHOUSE_DOMAIN=learn.example.com
HTTP_PORT=443
NEXT_PUBLIC_LEARNHOUSE_BACKEND_URL=https://learn.example.com/
NEXT_PUBLIC_LEARNHOUSE_API_URL=https://learn.example.com/api/v1/
NEXT_PUBLIC_LEARNHOUSE_DOMAIN=learn.example.com
NEXT_PUBLIC_LEARNHOUSE_TOP_DOMAIN=example.com
NEXT_PUBLIC_LEARNHOUSE_HTTPS=true
NEXT_PUBLIC_LEARNHOUSE_DEFAULT_ORG=default

# Backend
LEARNHOUSE_SQL_CONNECTION_STRING=postgresql://learnhouse:change-me@db:5432/learnhouse
LEARNHOUSE_REDIS_CONNECTION_STRING=redis://redis:6379/learnhouse
LEARNHOUSE_COOKIE_DOMAIN=.example.com
LEARNHOUSE_PORT=9000

# Segurança e bootstrap
LEARNHOUSE_AUTH_JWT_SECRET_KEY=replace-with-at-least-32-random-characters
LEARNHOUSE_INITIAL_ADMIN_EMAIL=admin@example.com
LEARNHOUSE_INITIAL_ADMIN_PASSWORD=change-this-password
LEARNHOUSE_INITIAL_ORG_NAME=Default Organization
LEARNHOUSE_INITIAL_ORG_SLUG=default

# Colaboração
COLLAB_INTERNAL_KEY=replace-with-random-shared-secret
LEARNHOUSE_REDIS_URL=redis://redis:6379
NEXT_PUBLIC_COLLAB_URL=wss://learn.example.com/collab

# IA, e-mail e armazenamento
LEARNHOUSE_IS_AI_ENABLED=False
LEARNHOUSE_EMAIL_PROVIDER=resend
LEARNHOUSE_CONTENT_DELIVERY_TYPE=filesystem
```
