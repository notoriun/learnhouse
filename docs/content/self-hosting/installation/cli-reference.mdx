# Referência da CLI

Referência completa de todos os comandos da CLI do Notoriun. A CLI é publicada como `learnhouse` no npm e normalmente é executada via `npx learnhouse@latest`.

## Instalação e Configuração

### `learnhouse setup`

Executa o assistente interativo de instalação. Este comando gera `docker-compose.yml`, `.env`, `learnhouse.config.json` e arquivos de configuração de nginx ou Caddy com base nas suas escolhas.

```bash
learnhouse setup
```

Flags: `--ci`, `--name`, `--domain`, `--port`, `--admin-email`, `--admin-password`, `--channel <stable|dev>`, `--no-start`.

Você pode reexecutar este comando em qualquer momento para reconfigurar sua instância. A configuração existente será preservada como padrão nas perguntas.

### `learnhouse config`

Exibe a configuração atual.

```bash
learnhouse config
```

### `learnhouse env`

Edita interativamente as variáveis de ambiente no seu arquivo `.env` (Domínio e Hospedagem, Banco de Dados e Redis, Segurança, IA, E-mail (Resend), Armazenamento S3, OAuth).

```bash
learnhouse env
```

<Callout type="info">
O comando `env` edita apenas um conjunto selecionado de variáveis. Credenciais SMTP (`LEARNHOUSE_SMTP_*`) não são editáveis por este comando — edite o `.env` diretamente se precisar delas.
</Callout>

## Gestão de Serviços

### `learnhouse start`

Inicia todos os serviços do Notoriun. Na primeira execução, baixa as imagens Docker necessárias antes de iniciar os contêineres.

```bash
learnhouse start
```

### `learnhouse stop`

Para todos os serviços do Notoriun em execução. Os dados são preservados em volumes do Docker.

```bash
learnhouse stop
```

### `learnhouse status`

Mostra o status de cada serviço do Notoriun.

```bash
learnhouse status
```

### `learnhouse logs`

Acompanha os logs dos contêineres de todos os serviços.

```bash
learnhouse logs
```

### `learnhouse update`

Atualiza o Notoriun para a versão mais recente ou uma versão específica. Baixa a imagem de destino, reescreve o `docker-compose.yml`, reinicia os serviços e pergunta sobre migrações de banco de dados.

```bash
learnhouse update
learnhouse update --version 1.4.2
learnhouse update --migrate       # aplica migrações automaticamente
learnhouse update --no-migrate    # pula migrações
```

### `learnhouse dev`

Inicia um ambiente de desenvolvimento completo (PostgreSQL + Redis em Docker, API + web + collab rodando localmente).

```bash
learnhouse dev
```

## Diagnósticos

### `learnhouse doctor`

Executa diagnósticos na sua instalação do Notoriun. Verifica disponibilidade do Docker, saúde dos contêineres, conflitos de porta, resolução de DNS e espaço em disco.

```bash
learnhouse doctor
```

### `learnhouse health`

Executa as verificações de saúde da CLI (conexão PostgreSQL, ping do Redis, endpoint HTTP de saúde, disco, recursos).

```bash
learnhouse health
```

### `learnhouse shell`

Abre um shell interativo dentro de um contêiner em execução, para depuração.

```bash
learnhouse shell
```

## Infraestrutura

### `learnhouse deployments`

Gerencia implantações e ajusta os limites de memória dos seus contêineres do Notoriun.

```bash
learnhouse deployments
```

## Backup e Restauração

### `learnhouse backup`

Cria um arquivo de dump PostgreSQL do banco de dados da sua instância (mais uma cópia do `.env`). Os arquivos são gravados em `<installDir>/backups/`.

```bash
learnhouse backup
```

### `learnhouse restore`

Restaura um banco de dados a partir de um arquivo de backup.

```bash
learnhouse restore <path/to/learnhouse-backup-<timestamp>.tar.gz>
```
