# Instalação Rápida

Siga estes passos para instalar e iniciar uma instância self-hosted do Notoriun usando a CLI do Notoriun.

## Passo 1: Execute o Assistente de Instalação

A forma mais rápida de começar é executar o assistente diretamente via `npx`. Nenhuma instalação global é necessária.

```bash
npx learnhouse@latest setup
```

<Callout type="info">
Você também pode usar os scripts de instalação em uma linha, se preferir:

**macOS / Linux:**
```bash
curl -fsSL https://raw.githubusercontent.com/notoriun/learnhouse/main/apps/cli/install.sh | bash
```

**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/notoriun/learnhouse/main/apps/cli/install.ps1 | iex
```
</Callout>

O assistente vai perguntar sobre:

- **Configuração de domínio** -- seu nome de domínio ou localhost para desenvolvimento local
- **Definições do banco de dados** -- configuração do PostgreSQL (padrões são fornecidos)
- **Credenciais de administrador** -- e-mail e senha para a conta de administrador inicial
- **Recursos opcionais** -- recursos de IA, entrega de e-mail e mais

O assistente gera `docker-compose.yml`, `.env`, `learnhouse.config.json` e uma configuração de nginx ou Caddy com base nas suas escolhas. Padrões sensatos são fornecidos para a maioria das opções -- você pode pressionar Enter para aceitá-los e ajustar as configurações depois.

## Passo 2: Inicie o Notoriun

Com a instalação concluída, inicie todos os serviços:

```bash
npx learnhouse start
```

A CLI vai baixar as imagens Docker necessárias (na primeira execução), criar os contêineres e iniciar todos os serviços. Isso normalmente leva um a dois minutos na primeira inicialização.

## Passo 3: Acesse o Notoriun

Com todos os serviços rodando, acesse o Notoriun no seu domínio configurado ou em:

- **http://localhost** (se estiver usando a configuração local padrão)

Entre com as credenciais de administrador fornecidas durante a instalação.

<Callout type="warning">
Troque a senha padrão de administrador após o primeiro login. As credenciais iniciais são destinadas apenas à primeira configuração. Vá até as configurações da sua conta para atualizar sua senha.
</Callout>

## Verificando a Instalação

Execute o diagnóstico integrado para verificar se tudo está funcionando:

```bash
learnhouse doctor
```

Este comando verifica o Docker, a saúde dos contêineres, disponibilidade de porta, resolução de DNS e espaço em disco, depois reporta qualquer problema encontrado.

Você também pode verificar o endpoint de saúde diretamente:

```bash
curl http://localhost/api/v1/health
```
