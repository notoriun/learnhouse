# Visão Geral da Instalação

A **CLI do Notoriun** é a forma recomendada e oficialmente suportada de instalar e gerenciar instâncias self-hosted do Notoriun. A CLI automatiza todo o processo de implantação, para você sair de um servidor limpo até uma instância do Notoriun rodando em minutos.

## O Que a CLI Faz

A CLI do Notoriun cuida de:

- **Assistente interativo de instalação** que conduz você pela configuração inicial
- **Geração de Docker Compose** com base nas suas escolhas de instalação
- **Geração de arquivo de ambiente** com todas as variáveis necessárias pré-configuradas
- **Gestão de serviços** para iniciar, parar e reiniciar sua instância
- **Verificações de saúde** para confirmar que todos os serviços estão rodando corretamente
- **Backups e restaurações** do seu banco de dados e conteúdo enviado
- **Atualizações** para baixar as imagens mais recentes do Notoriun e aplicá-las

<Callout type="info">
Você não precisa criar ou editar arquivos de Docker Compose manualmente. A CLI os gera e gerencia para você, com base nas suas escolhas de configuração.
</Callout>
