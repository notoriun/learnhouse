# Requisitos de Sistema

Antes de instalar o Notoriun, confirme que seu servidor atende aos seguintes requisitos.

## Requisitos de Software

| Software | Versão Mínima | Observações |
|---|---|---|
| Docker Engine | 20.10+ | Necessário para rodar contêineres |
| Docker Compose | 2.0+ | Incluído no Docker Desktop; instale separadamente no Linux |
| Node.js | 18+ | Necessário para rodar a CLI do Notoriun |
| npm | 8+ | Vem com o Node.js |

## Requisitos de Hardware

| Recurso | Mínimo | Recomendado |
|---|---|---|
| RAM | 2 GB | 4 GB |
| Espaço em disco | 10 GB | 20 GB+ |
| CPU | 1 núcleo | 2+ núcleos |

O uso de disco vai crescer com o tempo, dependendo da quantidade de conteúdo enviado (vídeos, documentos, imagens). Planeje a capacidade de armazenamento de acordo, se você espera uso intenso.

## Sistema Operacional

O Notoriun é suportado em:

- **Linux** (Ubuntu 20.04+, Debian 11+, CentOS 8+, ou qualquer distribuição com suporte a Docker)
- **macOS** (com Docker Desktop)
- **Windows** (via WSL2 com Docker Desktop)

Linux é recomendado para implantações em produção.

## Requisitos de Rede

- A porta **80** (HTTP) e/ou porta **443** (HTTPS) devem estar disponíveis
- Acesso à internet de saída é necessário durante a instalação, para baixar imagens Docker
- Um nome de domínio é recomendado para uso em produção, mas não é obrigatório para testes locais

## Verificando os Pré-requisitos

Execute os comandos a seguir para verificar se seu sistema está pronto:

```bash
# Verifica o Docker
docker --version

# Verifica o Docker Compose
docker compose version

# Verifica o Node.js
node --version

# Verifica o npm
npm --version
```

Todos os comandos devem retornar números de versão iguais ou superiores aos mínimos listados acima.
