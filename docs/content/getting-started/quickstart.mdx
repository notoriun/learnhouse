# Primeiros Passos Rápidos

Rode o Notoriun na sua própria infraestrutura usando a CLI. Você vai precisar do [Docker](https://docs.docker.com/get-docker/) e do [Node.js](https://nodejs.org/) (v18+) instalados.

## 1. Rode o assistente de instalação

```bash
npx learnhouse@latest setup
```

O assistente interativo conduz você pela configuração de domínio, configuração do banco de dados, criação da conta de administrador e recursos opcionais (IA, e-mail, armazenamento, OAuth).

## 2. Inicie a plataforma

```bash
npx learnhouse start
```

Sua instância estará disponível em `http://localhost` (ou no domínio que você configurou durante a instalação).

## 3. Gerencie sua instância

```bash
npx learnhouse stop     # Para todos os serviços
npx learnhouse logs     # Acompanha os logs
npx learnhouse backup   # Faz backup do banco de dados
npx learnhouse doctor   # Executa diagnósticos
```

<Callout type="info">
Para opções detalhadas de instalação, veja o guia de [Instalação Rápida](/self-hosting/installation/quick-install). Para variáveis de ambiente e configuração, veja [Configuração](/self-hosting/configuration).
</Callout>
