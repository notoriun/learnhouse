# Arquitetura do Backend

O backend do Notoriun é uma aplicação **FastAPI** escrita em Python, localizada em `apps/api` no
projeto. Ele serve como a camada de API central que lida com toda a lógica de negócio e a gestão
de dados.

## Stack de Tecnologia

- **FastAPI** 0.135.3 -- Framework web Python de alta performance
- **Python 3.14**
- **SQLModel** 0.0.38 -- ORM para interações com o banco de dados (construído sobre SQLAlchemy e
  Pydantic)
- **Alembic** -- Gestão de migrações de banco de dados
- **PostgreSQL 16** com a extensão **pgvector** -- Banco de dados relacional principal
- **redis-py** 7.4.0 -- Cliente Redis para Python
- **Uvicorn** 0.44.0 -- Servidor ASGI
- **uv** -- Gerenciador de pacotes Python

## Dependências Principais

- **psycopg2-binary** -- Adaptador PostgreSQL
- **pyjwt[crypto]** -- Manipulação de tokens JWT
- **pwdlib[argon2]** -- Hashing de senha com Argon2
- **google-genai** 1.71.0 -- Integração com IA Gemini (o único provedor de IA)
- **llama-index-core + pgvector** -- RAG e embeddings vetoriais
- **stripe** -- Processamento de pagamentos
- **workos** -- SSO Enterprise
- **boto3** -- Armazenamento compatível com S3
- **resend** -- E-mail transacional
- **sentry-sdk** -- Rastreamento de erros e monitoramento

## Configuração

O backend usa um sistema de configuração dual:

- **Config YAML** em `config/config.yaml` para configurações estruturadas
- **Variáveis de ambiente** que sobrescrevem os valores do YAML quando definidas

O prefixo de API para todos os endpoints é `/api/v1/`.

## Responsabilidades

O backend lida com todas as operações centrais da plataforma:

- **Autenticação e autorização** -- Autenticação por token baseada em JWT com controle de acesso
  baseado em papéis
- **Gestão de curso** -- Operações CRUD para organizações, cursos, capítulos e atividades
- **Gestão de usuário** -- Registro, perfis e permissões
- **Armazenamento de arquivos e envios** -- Manipulação de envios de mídia com suporte a
  filesystem local e armazenamento compatível com S3 (via boto3)
- **Recursos de IA** -- Integração com Google Gemini e LlamaIndex para assistência de
  aprendizado e RAG
- **Busca** -- Indexação de conteúdo e busca em cursos e atividades
- **Pagamentos** -- Integração com Stripe para monetização de curso
- **E-mail** -- E-mail transacional via Resend

## Camada de Banco de Dados

O SQLModel é usado como ORM, conectando-se a um banco de dados PostgreSQL 16 com a extensão
pgvector para embeddings de IA. Os modelos de banco de dados definem o schema para todas as
entidades: organizações, usuários, cursos, capítulos, atividades, coleções e mais. As migrações
são gerenciadas com **Alembic** para manter o schema sincronizado entre ambientes.

## Cache

O Redis é usado para:

- **Cache de resposta** -- Dados acessados frequentemente são armazenados em cache para reduzir
  a carga no banco de dados.
- **Dados de sessão** -- Informações temporárias de sessão são armazenadas no Redis para
  recuperação rápida.

## Documentação da API

O FastAPI gera automaticamente documentação interativa da API, mas ela só está disponível quando
executado em modo de desenvolvimento.

<Callout type="info">

## Estrutura de Diretórios

```
apps/api/
├── src/
│   ├── routers/      # Definições de rota da API
│   ├── db/           # Definições de tabela SQLModel
│   ├── services/     # Lógica de negócio
│   ├── security/     # Autenticação e autorização
│   └── core/         # Configuração e dependências
├── migrations/       # Migrações de banco de dados Alembic
├── ee/               # Recursos da Edição Enterprise
└── config/           # Arquivos de configuração YAML
```

## Desenvolvimento

O backend roda na **porta 1338** por padrão durante o desenvolvimento local (configurável via
`LEARNHOUSE_PORT`). Em implantações Docker de produção, ele roda na porta 9000. Instale as
dependências e execute o servidor:

```bash
uv sync              # instala dependências
uv run python app.py # inicia o servidor de dev (que chama o uvicorn internamente)
```

Ao usar a CLI do Notoriun (`learnhouse dev`), o backend inicia automaticamente com hot reload
ativado.
