# Arquitetura do Frontend

O frontend do Notoriun é uma aplicação **Next.js 16** localizada em `apps/web` no projeto. Ele
serve como a interface de usuário principal para alunos, instrutores e administradores.

## Stack de Tecnologia

- **Next.js 16.2.3** com o App Router (saída standalone)
- **React 19.2.5** com Server Components
- **TypeScript 6.0.2**
- **TailwindCSS v4** para estilização
- **Bun** como gerenciador de pacotes
- **Turbopack** para builds de desenvolvimento (`next dev --turbopack`)
- **SWR** para busca de dados no lado do cliente

## Dependências Principais

- **@tiptap/core** -- Editor de texto rico baseado em blocos
- **@radix-ui** -- Primitivas de UI acessíveis e sem estilo
- **@hocuspocus/provider** -- Cliente de colaboração em tempo real
- **yjs** -- Biblioteca CRDT para edição colaborativa livre de conflitos
- **@codemirror** -- Componente de editor de código
- **recharts** -- Gráficos e visualização de dados
- **formik / yup** -- Manipulação e validação de formulário
- **motion** -- Biblioteca de animação
- **i18next** -- Internacionalização
- **wavesurfer.js** -- Player de áudio/podcast
- **jspdf / html2canvas** -- Geração de certificado
- **unsplash-js** -- Integração de imagens do Unsplash

## App Router

O frontend usa o App Router do Next.js, que permite:

- **Server Components por padrão** -- Páginas e layouts renderizam no servidor, reduzindo o
  JavaScript do lado do cliente e melhorando os tempos de carregamento inicial.
- **Client Components quando necessário** -- Elementos interativos optam por renderização no
  cliente com a diretiva `"use client"`.
- **Streaming e Suspense** -- O conteúdo é transmitido progressivamente para o navegador conforme
  fica pronto.
- **Grupos de Rota e Layouts** -- Layouts compartilhados e roteamento aninhado mantêm o código
  organizado.

## Autenticação

A autenticação é feita via **tokens JWT** emitidos pelo backend FastAPI. No login, o backend
define um `access_token_cookie` (HS256, expiração de 8 horas) que o frontend anexa às
requisições de API. Rotas protegidas verificam uma sessão válida antes de renderizar.

## Comunicação com o Backend

O frontend se comunica com o backend FastAPI via HTTP. As chamadas de API são feitas a partir de:

- **Server Components** -- Os dados são buscados no momento da requisição no servidor, o que
  mantém tokens sensíveis fora do cliente.
- **Client Components** -- Recursos interativos fazem chamadas de API diretamente do navegador
  usando **SWR** para cache e revalidação.

## Estrutura de Diretórios

```
apps/web/
├── app/           # Páginas e layouts do App Router
├── components/    # Componentes de UI reutilizáveis
├── services/      # Cliente de API e funções de serviço
├── hooks/         # Hooks React compartilhados
├── lib/           # Utilitários e helpers de cliente
├── locales/       # Recursos de tradução i18next
├── styles/        # Estilos globais
├── ee/            # Componentes da Edição Enterprise
└── public/        # Assets estáticos
```

## Desenvolvimento

O frontend roda na **porta 3000** durante o desenvolvimento local. Inicie o servidor de dev com o
Turbopack ativado:

```bash
bun dev  # executa next dev --turbopack
```

Ao usar a CLI do Notoriun (`learnhouse dev`), o frontend inicia automaticamente com hot reload
ativado.
