# Desenvolvedores

Bem-vindo à documentação para desenvolvedores do Notoriun. Esta seção cobre tudo o que você
precisa para entender, construir e contribuir com a plataforma Notoriun.

## Estrutura do Projeto

O Notoriun é organizado como um monorepo contendo quatro aplicações principais:

| App | Tecnologia | Descrição |
| --- | --- | --- |
| **web** | Next.js (React) | Aplicação web de frontend |
| **api** | FastAPI (Python) | API REST de backend |
| **collab** | Hocuspocus | Servidor WebSocket de colaboração em tempo real |
| **cli** | Commander (Node.js) | Interface de linha de comando para desenvolvimento e gestão |

Todas as quatro apps vivem no diretório `apps/` no
[repositório do Notoriun](https://github.com/notoriun/learnhouse).
