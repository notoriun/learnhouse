# Referência da API

A API do Notoriun é um serviço RESTful construído com **FastAPI**. Ela alimenta todas as
operações da plataforma, da autenticação de usuário à gestão de curso e recursos de IA. Todos os
endpoints têm o prefixo `/api/v1/`.

## Referência Completa da API

<Callout type="info">
A **[Referência Completa da API](/reference)** documenta todo endpoint público — esquemas de
requisição e resposta, exemplos em cURL/JavaScript/Python com seu próprio token substituído, e um
playground interativo direto no navegador. Ela é gerada diretamente a partir da especificação
OpenAPI em produção, então nunca fica desatualizada.
</Callout>

## URL Base

No desenvolvimento local, a API está disponível em:

```
http://localhost:1338/api/v1/
```

Em produção, a API é servida detrás de um proxy reverso sob `/api/v1/` no seu próprio domínio.

## Formato de Resposta

Todas as respostas da API são retornadas como JSON. Respostas de sucesso normalmente incluem os
dados solicitados diretamente, enquanto respostas de erro seguem esta estrutura:

```json
{
  "detail": "Descrição do erro"
}
```

## Especificação OpenAPI

Como a API é construída com FastAPI, uma especificação OpenAPI legível por máquina é servida em
`/openapi.json` no domínio da sua instância. Use-a para gerar bibliotecas cliente ou importar a
API em ferramentas de teste. (A interface interativa do Swagger em `/docs` só é ativada em
instâncias de desenvolvimento.)
