## Padrões Comuns

- Todos os endpoints têm o prefixo `/api/v1/`.
- Os recursos seguem as convenções REST padrão: `GET` para listar ou obter, `POST` para criar,
  `PUT` para atualizar, `DELETE` para remover.
- Endpoints de criação/atualização geralmente aceitam **dados multipart form** em vez de JSON,
  já que muitos também aceitam envio de arquivos (ex.: miniaturas, avatares).
- Endpoints autenticados exigem o cabeçalho `Authorization: Bearer <token>` ou o cookie
  `access_token_cookie`.
- Acesso programático usa tokens de API com o prefixo `lh_` (plano Pro).
- As respostas são retornadas como JSON.

Para uma instância de desenvolvimento local, a interface interativa do Swagger também permanece
disponível em [http://localhost:1338/docs](http://localhost:1338/docs).
