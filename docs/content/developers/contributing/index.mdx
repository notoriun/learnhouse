# Contribuindo com o Notoriun

Obrigado pelo seu interesse em contribuir com o Notoriun! Seja corrigindo um bug, adicionando um
recurso, ou melhorando a documentação, suas contribuições são bem-vindas.

## Primeiros Passos

1. **[Configure seu ambiente de desenvolvimento](/developers/contributing/dev-environment)** --
   Coloque uma instância local do Notoriun em execução usando a CLI do Notoriun.
2. **[Revise as diretrizes de contribuição](/developers/contributing/guidelines)** -- Entenda
   nosso fluxo de trabalho, estilo de código e expectativas para pull requests.

## Encontrando Trabalho

O melhor lugar para começar é a página de
[issues do GitHub do Notoriun](https://github.com/notoriun/learnhouse/issues). Procure por
issues rotuladas:

- **`help wanted`** -- Issues em que contribuições da comunidade são especialmente bem-vindas.
- **`good first issue`** -- Tarefas menores e bem definidas, ideais para quem contribui pela
  primeira vez.

Se você tem uma ideia para um novo recurso, abra uma issue primeiro para discuti-la com os
mantenedores antes de começar a trabalhar.

## Dúvidas

Se você tiver dúvidas sobre como contribuir, sinta-se à vontade para abrir uma discussão no
[repositório do GitHub](https://github.com/notoriun/learnhouse) ou entrar em contato com os
mantenedores através do rastreador de issues.
