# Configuração do Ambiente de Desenvolvimento

A CLI do Notoriun fornece uma forma simplificada de configurar e executar todo o ambiente de
desenvolvimento com um único comando.

## Pré-requisitos

Certifique-se de ter o seguinte instalado antes de continuar:

- **Docker** (com Docker Compose v2)
- **Node.js 18+**
- **[Bun](https://bun.sh/)** — usado para instalar e executar os workspaces web e collab
- **[uv](https://docs.astral.sh/uv/)** — usado para gerenciar e executar a API Python

<Callout type="warning">
Certifique-se de que o Docker tenha pelo menos **4GB de RAM** alocados. Você pode verificar e
ajustar isso no Docker Desktop em Settings &gt; Resources.
</Callout>

<Callout type="info">
`npx learnhouse dev` executa `bun install` e `uv sync` para instalar as dependências do projeto,
mas **não** instala o `bun` ou o `uv` propriamente — instale-os no seu host primeiro.
</Callout>

## Passos de Configuração

### 1. Clone o Repositório e Inicie o Desenvolvimento

```bash
git clone https://github.com/notoriun/learnhouse && cd learnhouse && npx learnhouse dev
```

Esse único comando cuida de tudo:

- **Inicia os serviços de apoio** -- PostgreSQL e Redis são lançados via Docker Compose.
- **Instala as dependências** -- Dependências Python são instaladas via `uv` e dependências
  JavaScript via `bun`, tudo automaticamente.
- **Inicia a API** -- O backend FastAPI inicia na porta 1338 com hot reload.
- **Inicia o frontend** -- O servidor de desenvolvimento do Next.js inicia com `--turbopack` e
  hot reload.
- **Inicia o servidor de colaboração** -- O servidor de colaboração Hocuspocus inicia via
  `tsx watch`.

Todos os serviços são coordenados automaticamente, então você não precisa gerenciá-los
individualmente.

## Acessando a Aplicação

Uma vez que `npx learnhouse dev` está em execução, você pode acessar:

| Serviço | URL |
| --- | --- |
| Frontend | [http://localhost:3000](http://localhost:3000) |
| API | [http://localhost:1338](http://localhost:1338) |
| Documentação da API (Swagger) | [http://localhost:1338/docs](http://localhost:1338/docs) |

<Callout type="info">
O Swagger UI em `/docs` só está disponível em modo de desenvolvimento. Instâncias de produção não
expõem a documentação interativa da API.
</Callout>

## Parando o Ambiente

Pressione `Ctrl+C` no terminal onde `npx learnhouse dev` está em execução para parar todos os
serviços.

## Solução de Problemas

- **Conflitos de porta** -- Certifique-se de que as portas 3000 (web), 1338 (API), 4000
  (collab), 5432 (Postgres), e 6379 (Redis) não estão em uso por outras aplicações.
- **Docker não está em execução** -- Garanta que o daemon do Docker está iniciado antes de
  executar `npx learnhouse dev`.
- **Problemas de dependência** -- A CLI instala todas as dependências automaticamente. Se você
  encontrar problemas, tente excluir os diretórios `node_modules` e `.venv` e executar
  `npx learnhouse dev` novamente.
